# Gulper

A browser game about feeding a giant Venus flytrap. Open `index.html` in any modern browser; there is no build step.

- **Aim** the trap with the mouse, a dragged finger, or the arrow keys / WASD.
- **Snap** with a click, a tap, or Space.
- Eat flies, moths, beetles, golden flies, bats, steak and pigeons to fill the fullness meter and add to the digested total.
- Wasps cost one of the three rosette leaves (your lives). Pebbles stun the jaws.
- Each growth stage (Seedling → Snapper → Bog Brute → Greenhouse Menace → Leviathan) widens the trap, extends its reach, unlocks bigger prey and regrows a leaf.
- Catches within 2.5 seconds of each other build a combo multiplier up to ×5.
- P or Escape pauses. Your best score is kept in the browser's local storage.
